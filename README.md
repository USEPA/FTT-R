# FTT-R
This is the repository for the FishToxTranslator R package that supports the Fish Toxicity Translator GUI.  This repo is where all changes, updates, and additions for the FishToxTranslator R package take place.  This package is not publicly available as of 12/12/23, but can be accessed with permissions of the creator. 
For more information contact Nate Pollesch, pollesch.nathan-at-epa.gov
